# 🎛️ Project Control

Um sistema centralizado para gerir e controlar o estado de execução de múltiplos projetos em tempo real.

## 🚀 O que faz

O **Project Control** permite alterar a disponibilidade ou execução de serviços e aplicações dependentes a partir de um único local. 

* **Controlo de Estado:** Define se um projeto está *Ativo*, *Parado*, *Em Manutenção*, etc.
* **Execução Condicional:** Aplicações externas (ex: mobile, web) consultam este painel antes de executar certas operações em produção.
* **Paragem Rápida:** Interrompe a operação de uma plataforma instantaneamente através da alteração do seu estado.

---

## 💻 Como Funciona

1. Acedes ao **Project Control**.
2. Selecionas o projeto desejado (ex: *App Mobile*).
3. Alteras o estado para **Parado** (ou outro estado pretendido).
4. O projeto de destino deteta a mudança e ajusta o seu comportamento automaticamente.

---

## 🛠️ Tecnologias

* Dashboard de Gestão
* API de Comunicação de Estado
